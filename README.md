# 📩 Spam Message Classifier

A Machine Learning-based **Spam Message Classifier** that automatically identifies whether a text message is **Spam** or **Ham (Not Spam)** using Natural Language Processing (NLP) and machine learning techniques.

## 📌 Project Overview

Spam messages are unwanted messages that may contain advertisements, scams, fraudulent links, or other unwanted content.

This project uses **Natural Language Processing (NLP)** and **Machine Learning** to analyze the content of a message and classify it into one of two categories:

- 🚨 **Spam** – Unwanted or potentially harmful message
- ✅ **Ham** – Legitimate/normal message

The goal is to build a simple and effective automated system for detecting spam messages.
